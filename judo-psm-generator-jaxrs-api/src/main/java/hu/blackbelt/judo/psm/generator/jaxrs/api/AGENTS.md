# `judo-psm-generator-jaxrs-api/src/main/java/hu/blackbelt/judo/psm/generator/jaxrs/api` — `@TemplateHelper` static resolvers the `rest/api` Handlebars templates call to derive Java names, DTO types, JAX-RS paths and PSM element streams

| File | Purpose |
|---|---|
| `AttributeHelper.java` | Maps `TransferAttribute` to generated Java field type and request/response inclusion. Exports `attributeTargetTypeDefinition`, `isOptionalAttribute`, `isRequestAttribute`, `isResponseAttribute`, `isParametrizedAttribute`, `hasQueryWithoutParamAnnotation`, `hasDefaultValueAnnotation`, `isDataProperty`. → see `AttributeHelper.java.AGENTS.md` |
| `JavaApiHelper.java` | Builds API-side package names, FQ class names, Java types. Exports `apiPackageName`, `namedElementApiFqName`, `namedElementApiRestFqName`, `applicationClassName`/`applicationFqName` (suffix `ApplicationConfig`), `enumFqName`, `queryCustomizerName`, `primitiveDataTypeDefinition(Primitive)`, `REST`=`rest`. → see `JavaApiHelper.java.AGENTS.md` |
| `JavaNamespaceHelper.java` | Escapes PSM names to legal Java identifiers, builds namespace paths. Exports `safeName(String)` (appends `_` for reserved words incl. `class`, `Class`, `int`, `interface`), `fqName(Namespace,separator,safeName)`, `namedElementPackageName`, `namedElementAsmName`, `relationAsmFqName`, `logicalFullName`, `DEFAULT_TRANSFER_OBJECT_TYPES`. → see `JavaNamespaceHelper.java.AGENTS.md` `fqName`, `relationAsmFqName`, `classifierAsmFqName` memoized per run via `ModelHelper.cached` (were static Guava caches). See change: JNG-6430 |
| `ModelHelper.java` | Streams PSM model for template `#each` roots, computes exposure closure. Exports `modelWrapper(Model)`, `getSpecifiedContainer`, `hasDocumentation`, `isMapped`, `isDerivedRelation`, `allExposedTransferObjectWithOperation(Model)`, `allAccessPointActor`, `allAccessPointActorWithRealm`, `allTransferObject`, `allEnumType`, `allRange`, `allQueryCustomizer`. → see `ModelHelper.java.AGENTS.md` `modelWrapper` built once per run per (ResourceSet, URI) under the class lock; package-private `cached(anchor,key,loader)` → `ModelCache`. `getAllExposedTransferObjectTypesFromAccessPoint` returns a `HashSet` → identity-hash iteration order (nondeterministic output order, pre-existing). See change: JNG-6430 `getAllExposedTransferObjectTypesFromAccessPoint` / `allExposedTransferObjectWithOperation` return `LinkedHashSet` ordered by model path (`inModelPathOrder`, container names, no template context — usable in factory expressions); was `HashSet` order → `*ApplicationConfigImpl.java` changed run to run. JNG-6430 |
| `ObjectTypeHelper.java` | Classifies `TransferObjectType`, derives DTO class names. Exports `isActorType`, `getRealm`/`getRealmLowerCase`, `getEntity`, `isEntity`, `hasCustomOperation`, `isRangeInputType`, `classNameFor{CreateRequest,RangeRequest,Request,Response}` plus `…Postfix` and `classNameLogicalFullNameFor…` variants. → see `ObjectTypeHelper.java.AGENTS.md` `isRangeInputType` uses a per-run identity set of GET_RANGE inputs; `getEntity`/`isEntity` a per-run default-representation map. See change: JNG-6430 |
| `OperationHelper.java` | Derives JAX-RS routing and input/output DTO names for `TransferOperation`. Exports `isBoundOperation`, `isCustomOperation`, `operationAsmFqName` (`<ns>.<TO>#<op>`), `isRangeOperation`, `isStateful`/`isStateless`, `toJAXRSPath(TransferOperation, Model)`, `getOperationInputFQNameFor…`, `getOperationOutputFQNameForResponse`, `getOperationTagName`, `getRealmsOfOperationLowerCase`. → see `OperationHelper.java.AGENTS.md` |
| `RelationHelper.java` | Maps `TransferObjectRelation` to generated relation types, collects embeddable relations. Exports `decorateWrapperType`, `relationTargetTypeDefinitionFor{CreateRequest,Request,RangeRequest,OperationInput,Response}`, `isParameterizedRelation`, `mappedRelationIsAssociation`, `allEmbeddedOrMappedRelation`, `allEmbeddedOrMappedRelationForCreate`. → see `RelationHelper.java.AGENTS.md` |
| `StoredVariableHelper.java` | Bridges generator context variables into static helpers via `ThreadLocalContextHolder`; `@TemplateHelper` + `@ContextAccessor`. Exports `bindContext(Map)`, `getApiPrefixLocal`, `isDebugPrint`, `isGenerateOptionalTypes`, `isGenerateOpenApiAnnotations`, `getBaseUrl`, `getAuthenticationUrl`, `getSpecificationVersionNumber`. → see `StoredVariableHelper.java.AGENTS.md` |
